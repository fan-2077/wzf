# Round 10 audit note — correct the 8-vehicle mask interpretation

Date: 2026-11-16

## Why this note exists

An independently completed one-incident 8-vehicle exhaustive run exists on branch `round10-eight-vehicle-20261116`:
- Run: 43846116043
- Artifact: `round10-eight-vehicle-evidence`, ID 14216235704
- 256/256 joint assignments completed; all routes, destinations and the 540-second fault were verified.
- All 256 combinations met the example queue cap.
- Exhaustive optimum: mask `00110110`, total arrival 12,294, versus all-wait 12,890.

The original summary claims that independently optimal single-vehicle actions combine to mask `01101100`, total 13,631, worse than all-wait by 741. This claim is **incorrect because of a bit-order mismatch**.

## Exact source bug

The simulator maps vehicle index `i` to integer bit `1 << i`:
`action = reroute if mask & (1 << i) else wait`.

But the result label is generated by:
`format(mask, '08b')`,
which prints the most significant bit first. Therefore, the first vehicle corresponds to the **rightmost** character of the displayed mask, not the leftmost.

The original local-mask construction concatenates per-vehicle decisions in vehicle order, left to right, then compares that string directly to the big-endian result labels. It reverses the intended assignment.

The local choices in vehicle order are:
`[wait, reroute, reroute, wait, reroute, reroute, wait, wait]`.

As a human-readable vehicle-order string this is `01101100`. But the corresponding integer mask is `00110110`, because vehicle 0 is the least significant bit. That is exactly the exhaustive global optimum.

Independent recomputation:
- Correct local mask label: `00110110`
- Correct local-choice assignment total: 12,294
- Exhaustive global optimum: `00110110`, total 12,294
- Difference: 0
- All-wait total: 12,890

Thus the 8-vehicle one-event experiment **does not demonstrate a gap between independently optimal actions and the joint optimum**. The 4-vehicle round-nine counterexample remains valid; this 8-vehicle one-event result is a counterexample to our hoped-for generalization.

The original artifact and summary are not modified. This correction supersedes only the claim about the local-best mask and its 741-second penalty.

## What this changes

Do not cite the one-event 8-vehicle experiment as evidence that local best actions combine badly. It demonstrates that exhaustive enumeration of 256 options is computationally feasible on the fixed runner and that all candidate actions were executable, but its local-best combination equals the joint optimum.

The current two-incident experiment on branch `round10-multi-incident-20261116` is designed to test whether coupling becomes stronger with two simultaneous faults at different intersections. It must be independently audited with explicit vehicle-index-to-mask mapping before any conclusion.

No LLM, AIOS, multi-agent collaboration, independent subagents, or competition speedup was demonstrated by the one-event 8-vehicle experiment.
